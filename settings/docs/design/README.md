# Drowned archive reference

The approved direction is J (Grotto), with the user's manual edits and the later
lit-edge sidebar and adjustable background changes. J2 (Colors) and J3 (AppLook)
show the palette and the settings window's own appearance controls. Map is the
proposed expanded inventory. These are archived design-canvas sources; their
`support.js` and canvas runtime belong to Claude's private artifact service.
They are reference material, not standalone web pages or application code.

SPEC.md preserves the final handoff verbatim. Its backend keys, existing-feature
claims and estimates must be checked against the real source. Its live-apply
pipeline and settings.wave include are later phases; the first implementation
retains the existing protected Draft/Apply pipeline, with live visual previews.
Do not interpret the sample status text, keybinds or monitor counts as real data.

Implementation proceeds in stages: theme and controls, registry/navigation,
compositor integration, palette editor, detected system backends, then remaining
pages. The first stage includes This app so the visual foundation is adjustable
and reviewable immediately. See ../STATUS.md for implemented scope and evidence.
